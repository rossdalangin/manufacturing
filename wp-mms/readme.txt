A complete Manufacturing Management System for WordPress.

== Description ==

This plugin provides a full suite of tools for managing a manufacturing business within the WordPress dashboard. It includes features for purchasing, inventory management, bill of materials (BOM), and production scheduling.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/wp-mms` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress
